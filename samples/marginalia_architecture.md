# Marginalia Project Architecture

Marginalia is an intelligent document exploration platform that allows researchers, analysts, and students to query their documents using natural language and receive verifiable citations.

## Supported Document Formats
1. Portable Document Format (.pdf)
2. Microsoft Word Documents (.docx, .doc)
3. Excel Spreadsheets and Macro Workbooks (.xlsx, .xlsm, .xls)
4. Comma-Separated Values (.csv)
5. Structured Data (.json, .html, .md, .txt)

## LangChain Integration
The system uses recursive character text splitting with an optimal chunk size of 750 characters and a 120 character overlap. This preserves paragraph context while ensuring granular passage-level citation accuracy.

## Citations Engine
Every answer generated by Marginalia references the exact source page or spreadsheet sheet where the evidence was extracted from.
